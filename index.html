云端数据说明
你的数据存在哪里？

每条记录都会保存三个副本，层层兜底，缺了谁都不怕：

① 本设备浏览器记录瞬间先存这里，断网也成功，秒级完成
② Supabase 云端约 2 秒后自动整包上传，手机电脑共享同一份数据
③ JSON 备份文件手动导出的终极保险，建议每季度存一份到电脑 / 网盘
断网或云端异常时

断网照常记录：数据在本设备暂存并标记「离线待同步」，联网后自动补传，无需任何操作。Supabase 免费版连续 7 天无访问会休眠（数据原样保留，唤醒约 1 分钟）；长期搁置时点一次保活链接即可防止休眠。

保活与巡检
平时什么都不用做，徽标显示「已同步」即一切正常
长期不用时每 1~2 周点一次保活链接（只读操作，不产生写入）
每季度导出 JSON 备份 + 到 Supabase 控制台看一次用量
与仓库文档 DATA.md 同源维护 · 数据流向 / 恢复方法详见 DATA.md
