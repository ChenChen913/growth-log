# 公众号成长日志 v3.1

一个部署在 GitHub Pages 上的**私人公众号运营日志**：记录每一篇文章、每一周的数据，自动生成趋势图表和月度/年度汇总。支持手机 / 电脑多设备云端实时同步，可安装到手机桌面像 App 一样使用。

> **开箱即用**：不配置任何云服务，仓库部署后即可直接使用（本地模式，数据存本设备浏览器）；首次访问有引导说明，超过 14 天未备份会自动提醒，后续可随时免费升级云同步。

> 由个人本地单文件工具升级而来，保留全部原有功能与设计风格。

## ✨ 功能

| 模块 | 说明 |
|------|------|
| 📊 数据总览 | 累计阅读 / 分享 / 周数统计卡，内容类型分布图（柱 / 饼切换），AI 辅助创作占比 |
| 📝 文章记录 | 增删改、类型筛选（文章 / 图文 / 视频 / 音频）、原创与 AI 参与标记、**标题搜索 + 日期范围筛选 + 排序** |
| 📈 周报告 | 周度数据（阅读 / 分享 / 粉丝 / 7 类阅读来源占比 / 感悟），趋势折线图（多指标 + 时间范围） |
| 🗓 月度年度 | 年份切换、年度四项总计、月度趋势柱状图、12 个月度卡片（含环比） |
| ☁️ 云端同步 | Supabase 免费云数据库，访问口令保护，手机电脑多端实时同步，离线暂存自动补传 |
| 📱 PWA | 可添加到手机主屏幕，全屏 App 体验，离线可浏览缓存 |
| 🛠 数据管理 | Canvas 生成分享卡片、导出 JSON 备份、导入历史数据（兼容 v2.0 旧版格式） |

## 🚀 快速部署

完整步骤（含 Supabase 配置、GitHub Pages 开启、旧数据迁移）见 **[DEPLOY.md](DEPLOY.md)**，全程约 15 分钟。

极简概览：

```bash
# 1. Supabase 创建项目，SQL Editor 执行 sql/setup.sql（先改口令）
# 2. 把 Project URL 和 anon key 填入 js/config.js
# 3. 本仓库推送到 GitHub，Settings → Pages 开启（main 分支 / root）
# 4. 访问 https://<你的用户名>.github.io/<仓库名>/
```

> 不配置 Supabase 也可以直接用——应用会以**本地模式**运行（数据仅存当前设备），之后随时可在 `js/config.js` 填入配置升级为云端同步。

## 💡 纯本地模式使用提示

- 数据保存在**当前设备浏览器**的 localStorage 中：换设备、清缓存前，先点「导出 JSON 备份」；
- 已有数据且超过 14 天未备份时，页面底部会出现备份提醒，点击「立即备份」即可一键导出（关闭后 7 天内不再提醒）；
- 手机浏览器菜单「添加到主屏幕」后可全屏使用，效果与 App 一致；
- 备份文件导入另一台设备即可完成数据迁移（相同记录自动去重）。

## 🔒 数据与隐私

- 数据整包存储在**你自己的 Supabase 项目**中，第三方（包括本仓库作者）无法读取；
- 访问口令以 bcrypt 哈希保存在数据库中，数据库两张表均启用 RLS 锁死，匿名密钥只能通过带口令校验的 RPC 函数读写；
- `js/config.js` 中的 anon key 是 Supabase 设计上的公开密钥，泄露无风险；
- 随时可用「导出 JSON 备份」把全部数据下载到本地留存。
