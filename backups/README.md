# 数据备份目录

> 本目录由「公众号成长日志」应用的数据备份自动持久化维护，防止数据丢失。
> 数据口径与恢复方法详见仓库根目录 [DATA.md](../DATA.md)。

## 文件说明

| 文件 | 含义 |
|------|------|
| `cloud_YYYY-MM-DD.json` | **云端全量备份**：直连 Supabase 拉取的权威整包（`_meta.source: "cloud"`），云端此刻有多少导多少 |
| `local_YYYY-MM-DD.json` | **本机快照**：导出时该设备内存中的数据（`_meta.version: "3.0"`） |
| `latest-cloud.json` | 最近一次云端全量备份（覆盖式更新，始终最新） |
| `latest-local.json` | 最近一次本机快照（覆盖式更新，始终最新） |
| `HISTORY.md` | 每次备份的索引（日期 / 计数） |

- 同一天多次导出会覆盖同名日期文件，旧版本仍保留在 git 历史中，可随时回溯。
- 想要最新全量数据：直接下载 `latest-cloud.json` 即可。

## 安全性

- 备份文件**不含访问口令、不含任何密钥**（应用口令仅以 bcrypt 哈希存于 Supabase，从不出现在数据中）。
- 每次入库前自动做结构校验 + 敏感字符串扫描，校验不过不会推送。

## 恢复方法

在网站「数据总览 → 数据管理 → 导入历史数据」选择任一备份 JSON 即可合并导入
（应用内置字段级清洗，相同记录自动去重），适合换设备 / 数据丢失时一键恢复。
